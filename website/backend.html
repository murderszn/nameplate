Facts are Append-Only

Service events, location changes, scans, and turnover audits are never deleted. Any corrections append new witnessed rows with human attribution.

Current State is a Projection

An asset's current unit location, condition grade, and lifetime repair spend are high-speed cached projections computed from ledger history.

Tenant Scope is Structural

Every customer record carries an org_id key. Application authorization guards and database Row-Level Security (RLS) guarantee isolation.

Offline is the Default State

UUIDv7 client keys, dual timestamps (occurred_at vs recorded_at), and monotonic change sequences prevent conflict data loss.

ACID Transaction Lineage

Atomic write pipeline.

Every field action executes across an isolated ACID transaction boundary, ensuring facts and derived state commit together with zero corruption.

TXN 01 // ONBOARDING

Hardware Tag Minting

Technician mints Crockford Base32 NPID, scans barcode, assigns category and initial unit location.

asset (INSERT)
+ asset_location (INSERT custody)
+ asset_identifier_scan (INSERT telemetry)
+ audit_log (INSERT actor)
TXN 02 // CUSTODY MOVE

Physical Asset Relocation

Appliance moved between units or transferred to the maintenance shop for staging.

asset_location (UPDATE to_ts = NOW())
+ asset_location (INSERT new target)
+ asset (UPDATE current_unit_id)
+ audit_log (INSERT delta)
TXN 03 // SERVICE EVENT

Field Repair & Part Swap

Technician diagnoses fault, records labor minutes, installs component, and closes work order.

service_event (INSERT fact + costs)
+ part_usage (INSERT component)
+ part_records (UPDATE installed_asset)
+ asset (UPDATE lifetime_service_cost)
+ work_orders (UPDATE status = closed)
TXN 04 // UNIT TURNOVER

Make-Ready Turn Audit

Walkthrough checks appliance roster against expected registry; missing items trigger investigations.

turns (INSERT / UPDATE status)
+ turn_items (INSERT findings[])
+ work_orders (INSERT auto-repair)
+ reconciliation_flag (INSERT missing)

Batch Ingestion Push

Field device reconnects to Wi-Fi/LTE, pushing queued mutations idempotently.

sync_batches (INSERT header)
+ sync_ops (INSERT applied receipts)

+ reconciliation_flags (INSERT conflicts)

Nightly Analytics Materialization

Multi-Tenant Isolation

Row-Level Security (RLS)

Database-level security policies strictly isolate portfolios. Every query is restricted by the tenant's cryptographic token:

  • Every tenant row carries mandatory org_id
  • PostgreSQL RLS policies reject cross-organization reads/writes
  • FastAPI / NestJS application guards enforce property-scoped permissions
ALTER TABLE assets ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON assets
  FOR ALL USING (org_id = current_setting('request.jwt.claim.org_id'));
High Throughput

Connection Pooling & Replicas

Separate connection pools for transactional field writes and heavy analytical reporting keep response times under 20ms:

  • PgBouncer / Supavisor manages client concurrency
  • Dedicated read replicas serve HQ depreciation and SLA reports
  • Prisma migrations and admin schema operations use direct connections
DATABASE_URL="postgresql://...pooler.../postgres?pgbouncer=true"
DIRECT_URL="postgresql://...direct.../postgres"
READ_REPLICA_URL="postgresql://...replica.../postgres"
